# 스펙 인덱스 (docs/spec)

`docs/spec/`는 **살아있는 계약 스펙(living contract specs)** 의 집입니다. 각 문서는
"무엇을 보장해야 하는가"를 선언적으로 기술하며, 구현 파일 참조·버그 이력·수정 지시는
담지 않습니다. 독자는 스펙 작성자입니다. (`spec-write` / `spec-tdd` 스킬과 짝을 이룹니다.)
