**배치 규칙**
1. 각 파트너의 2개 날짜는 `[last_order_date + 1일, 2026-04-16]` 사이의 평일에서 선택
2. 하루 최대 2건으로 제한 (자연스러운 분산)
3. 선택 창이 좁은 파트너부터 먼저 배치 (backtracking 대신 greedy)
4. WJ바이오는 이미 2026-04-16까지 주문이 있어 창이 1일밖에 안 되므로 예외적으로 최근 7일 안에서 배정 (로직: `start > target_end` 인 경우 7일 역산)

## 이 계획이 후속 스토리에 쓰이는 방식

- **US-005 Inquiry 메일:** 플로우당 1건, 총 22건. 파트너 `email` 있는 경우 From 표기에 사용, 수신은 테넌트 mail_server 내부로만.
- **US-006 CRM Lead:** `create_date`/`date_open`에 위 `flow_N_date` 사용. `partner_id`는 배정 파트너.
- **US-007 Sale Order:** `date_order = lead.create_date + 0~2일` (같은 날 또는 다음 영업일).
- **US-008 Invoice:** `invoice_date = SO.date_order + 0~3일`.
- **US-009 Purchase Order:** `date_order = SO.date_order + 0~2일`.
